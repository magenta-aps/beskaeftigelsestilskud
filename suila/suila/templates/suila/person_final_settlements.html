    {% translate 'Betingelser og størrelsen af din Suila-tapit' %}

    {% blocktranslate trimmed %} Af lovbekendtgørelsens § 38 a, stk. 2 fremgår, at du skal være fuldt skattepligtig til Grønland og ikke må være bruttobeskattet for at kunne modtage Suila-tapit. {% endblocktranslate %}

    {% blocktranslate trimmed %} Af § 38 b, stk. 1 fremgår: {% endblocktranslate %}

    • {% blocktranslate trimmed %} Størrelsen af dit Suila-tapit er 17,5 % af den del af dit indkomstgrundlag, der er over 70.000 kr. (for 2025). {% endblocktranslate %}
    • {% blocktranslate trimmed %} Dit Suila-tapit kan dog ikke være højere end 15.750 kr. (for 2025) (§ 38 b, stk. 2). Hvis dit indkomstgrundlag er over 250.000 kr. (for 2025) reduceres dit Suila-tapit med 6,3 % af dit indkomstgrundlag (§ 38 b, stk. 3). {% endblocktranslate %}

    {% blocktranslate trimmed %} Det betyder, at du ikke er berettiget til Suila-tapit hvis dit indkomstgrundlag er over 500.000 kr. (for 2025). {% endblocktranslate %}
